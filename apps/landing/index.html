開發者優先

一個 API,三種接法。

浮動小工具、REST API,或型別完整的 TypeScript SDK,選你順手的方式接上。

terminal
curl https://api.embaid.chat/v1/chat \
  -H "X-API-Key: sk_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{"message":"退款要多久?"}'
app.ts
import { EmbAId } from "@embaid/sdk";

const client = new EmbAId({ apiKey: process.env.EMBAID_KEY });

const stream = await client.chat.stream({
  projectId: "proj_xxx",
  message: "退款政策是什麼?",
});

for await (const token of stream) {
  process.stdout.write(token.text);
}
