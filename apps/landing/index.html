核心能力

不只是把文件塞進提示詞

每個環節都為「答得準、答得可信」設計。從檢索、重排序到婉拒與稽核, 一條龍處理 RAG 最難的地方。

混合檢索

向量語意與關鍵字語彙雙軌並行,以 RRF 融合排序,長尾專有名詞也找得到。

交叉重排序

Cross-encoder 對候選段落逐一評分,把最相關的證據推到最前面再交給模型。

對話式改寫

多輪對話自動補全指代與省略,把「那它呢?」還原成完整、可檢索的問題。

低信心婉拒

證據不足時不硬掰,誠實回覆「文件裡沒有」,並把問題記錄為知識缺口。

可稽核軌跡

每則回答都能回溯:檢索了哪些段落、分數多少、為何選它,決策全程透明。

語意快取

語意相近的問題直接命中快取,省下重複的模型花費,回應更快、成本更低。

運作原理

三步,從一堆文件到一個會回答的助理

  1. 01

    匯入內容

    上傳 PDF、Word、Markdown,或直接連結網站與 Sitemap。系統自動抓取、清洗、切塊。

  2. 02

    索引與嵌入

    帶上下文的分塊嵌入寫入向量庫,同時建立語彙索引,支撐後續的混合檢索。

  3. 03

    嵌入或呼叫

    貼一段 script 就有浮動助理,或用 REST API 與 SDK 把問答能力接進任何產品。

一個 API,三種接法

浮動小工具、REST API、或型別完整的 TypeScript SDK,選你順手的方式接上。

terminal 
curl https://api.proprai.chat/v1/chat \
  -H "X-API-Key: sk_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{"message":"退款要多久?","project_id":"proj_xxx"}'
app.ts 
import { ProprAI } from "@proprai/sdk";

const client = new ProprAI({ apiKey: process.env.PROPRAI_KEY });

const stream = await client.chat.stream({
  projectId: "proj_xxx",
  message: "退款政策是什麼?",
});

for await (const token of stream) {
  process.stdout.write(token.text);
}
